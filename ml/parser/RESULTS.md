## Read this before trusting the numbers

- **The rules were written while looking at these same 40 examples**, so "Rules only" (and both hybrids) are optimistic here. A fair comparison needs a held-out set of new messy searches the rules have never seen; the models (GLiNER2, Qwen) never saw this set, so their numbers are closer to what new text would get.
- 40 examples is small: one example is 2.5 percentage points.
- Latency is on a MacBook CPU; Qwen's first call (model load) is excluded by a warm-up call.
